We built a Traceroute Visualizer using Python in Jupyter Notebook to track how network packets travel from our computer to a remote destination. Using Windows' tracert command, we traced the route to a University of Massachusetts server in the USA. We collected information about each hop, including its IP address and round-trip time (RTT), which tells us how long a probe takes to travel to the destination and receive a response.

We then used Python libraries such as Pandas, Requests, and Plotly to process the traceroute results, retrieve approximate geographical information for each IP address, and visualize the packet's journey on an interactive world map. The visualization shows the estimated route through Nepal, India, the UK, and the USA, while allowing us to inspect individual hops, their locations, ISPs, and latency.
